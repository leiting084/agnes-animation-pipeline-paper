# 分析与实验脚本

本目录脚本用于复现论文中的统计结果与图表。

## 当前内容

- `classify_failure_modes.py` —— 失败模式分类 + **场景混淆自动校验**
- `run_ablation.py` —— 负向提示词消融实验驱动（待补）

## 使用前的必读

> ⚠️ `s76 / s80 / s90` 是场景号，**不是批次号**。
> 这三个场景 100% 判退，`s100` 通过率 83%。
> 直接跨场景对比会把**场景内容差异**误判为**方法有效性差异**。
> 脚本内置了检测逻辑，跑起来会先做这个校验。

## 合规边界

本目录产出的是**统计输出**。这些输出在论文正式发表前**不应公开**，
以免耗尽论文原创性。脚本本身可以公开，输出不能。
